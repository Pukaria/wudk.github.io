## 🧠 一、CTA策略矩阵研发与核心逻辑

我参与设计了包含8个独立策略的CTA策略矩阵，覆盖玉米、白糖、铁矿石、焦煤、菜籽粕、尿素、棕榈油等多个商品期货主力合约。

### 1. 策略矩阵总览

| 编号 | 策略名称 | 交易品种 | 核心类型 |
|:---:|:---|:---|:---|
| S1 | 反马丁格尔+布林带反转 | 玉米 | 趋势跟踪（盈利加仓） |
| S2 | 马丁格尔倍投+布林带反转 | 白糖 | 趋势反转（亏损加仓） |
| S3 | 高波动趋势回调 V3.6.10 | 铁矿石 | 回调突破 |
| S4 | 高波动趋势回调 V3.7.1 | 铁矿石 | 趋势突破（纯趋势） |
| S5 | **EMA89角度过滤策略** | 焦煤 | 趋势突破（角度过滤） |
| S6 | 高波动趋势回调 V3.7.4 | 菜籽粕 | 纯多头趋势跟踪 |
| S7 | 多因子ADX趋势跟踪 | 尿素 | 趋势跟踪（多因子共振） |
| S8 | 多因子ADX趋势跟踪 | 棕榈油 | 趋势跟踪（多因子共振） |

### 2. 核心策略逻辑部分拆解

**（1）S5 焦煤：EMA89角度过滤策略（实盘主力）**
- **核心创新**：传统趋势策略容易被震荡市反复打损，该策略通过计算 `EMA89` 的几何斜率角度（`ATAN((EMA89-前30根EMA89)/ATR) * 57.2958`）来量化趋势强度。多头阈值设为 `9°`，空头设为 `-11°`（非对称设计，因焦煤下跌更剧烈）。
- **入场结构**：“突破前高 → 回调超1倍ATR → 再次突破前高”的三段式结构。
- **风控体系**：固定风险法（单笔7000元风险倒推手数）+ 20跳最小保护间距 + 尾盘强平（14:50/22:50）。

## 🖥️ 二、量化路演看板系统搭建（Dash + Plotly）

为了将晦涩的策略数据和零散的本地回测报告转化为直观的、可向资方路演的交互式 Web 系统，我基于 Python 从零搭建了策略路演看板

### 1. 核心功能模块
- **KPI 动态联动卡片**：下拉切换品种，瞬时刷新收益率、夏普比率、胜率、盈亏比等10项核心指标。
- **净值/回撤双轴图**：使用 `make_subplots` 绘制上下双图，自动标注最大回撤点的“星号”。
- **月度收益热力图**：将盈亏序列聚合成月度收益率，用红绿渐变色直观展示不同年份、月份的表现。
- **收益风险四象限图**：气泡散点图，X轴为最大回撤，Y轴为收益率，**气泡大小代表夏普比率**。自动划分“最佳象限”与“危险象限”。
- **蒙特卡洛路径模拟**：基于历史收益率进行重采样，绘制 5%-95% 的置信区间带，评估尾部风险。
